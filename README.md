## 📘 Descripción general del sistema
Este proyecto corresponde a la primera actividad sumativa de la asignatura *Desarrollo Orientado a Objetos I*.

Consiste en un sistema básico para la agencia de turismo "Llanquihue Tour", utilizando los principios básicos de la programación orientada a objetos en Java.

El objetivo es poder representar y organizar la información de aquellas personas que se encuentran vinculadas a la organización, registrando sus datos personales, como nombre, RUT, teléfono, dirección y correo, utilizando encapsulamiento, herencia y composición.

---

## 🧱 Estructura general del proyecto

```plaintext
📁 src/
├── app/
│   └── Main.java
│
└── model/
    ├── Persona.java
    ├── Cliente.java
    └── Ubicacion.java
```
### Clases implementadas
El proyecto contiene tres clases principales:

**1. Persona**

Es la clase que contiene nombre, RUT, teléfono, y ubicación.

**2. Cliente**

Es la clase que hereda de Persona. Indica a los clientes de la agencia y agrega un correo electrónico.

**3. Ubicación**

Es la clase que guarda la ubicación de una persona considerando; dirección, ciudad y región.

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Abre el proyecto en IntelliJ IDEA.

2. Ubicar el archivo `Main.java` dentro del paquete `app`.

3. Ejecuta el método `main`.

4. Visualiza en la consola los datos de los tres clientes registrados.
